# Minimal dependencies for the conversion / quantization pipeline.
# Install into a SEPARATE venv from ComfyUI -- these tools are
# independent of the inference-time ComfyUI environment.
#
# Recommended (uv-based, matches tools/README.md):
#
#     uv venv venv --python 3.11
#     source venv/bin/activate          # (Linux/macOS)
#     venv\Scripts\activate.bat         # (Windows)
#     uv pip install -r tools/requirements-conversion.txt
#
# Plain pip also works:
#
#     python -m venv venv
#     source venv/bin/activate
#     pip install -U pip
#     pip install -r tools/requirements-conversion.txt
#
# This is NOT the same as the root-level requirements.txt; that one only
# lists what the ComfyUI custom node needs at *inference* time (which is
# tiny because ComfyUI already provides torch / numpy / etc.).
#
# Versions below are minimums known to work, not pins -- newer is fine.
# Floors track a recently validated environment (Python 3.11, CUDA 13).
